# OpenCode Context View

Port the reliable context-viewing behavior of Pi Context View to OpenCode V2.
Use the published master spec in GitHub Issues as the scope.
Use Conventional Commits, Conventional Branches, Conventional PR titles,
and Semantic Versioning.

## Agent skills

### Issue tracker
Track issues and specs in this repository's GitHub Issues.
Before issue operations, read `docs/agents/issue-tracker.md`.

### Triage labels
Use the five default triage labels.
Before triage, read `docs/agents/triage-labels.md`.

### Domain docs
Use a single-context domain layout.
Before codebase exploration or specification, read `docs/agents/domain.md`.
